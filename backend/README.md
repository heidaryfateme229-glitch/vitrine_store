# Vitrin Store API

این سرویس Express، رابط فروشگاه را از پوشهٔ والد ارائه می‌کند و داده‌ها را در PostgreSQL نگه می‌دارد. برای نصب محلی، فایل `.env.example` را به `.env` کپی و مقادیر را تکمیل کن؛ سپس `npm install` و `npm run dev` را اجرا کن.

مسیرهای اصلی: `/api/health`، `/api/products`، `/api/auth/register`، `/api/auth/login`، `/api/orders` و مسیرهای `/api/admin/*`.

مقادیر محرمانه فقط باید در فایل `.env` محلی یا بخش Environment سرویس میزبانی قرار بگیرند؛ فایل `.env` را در Git ثبت نکن.
